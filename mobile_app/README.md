# SGEC Mobile App (Flutter)

This folder contains only the Dart source (`lib/`), `pubspec.yaml`, and
`assets/`. The native Android/iOS project folders (`android/`, `ios/`, etc.)
are **not included** — they're machine-generated by the Flutter SDK and
shouldn't be hand-written or checked in from a scaffold like this. You'll
generate them in step 1 of the main build guide.

## After running `flutter create .` (step 1 of the build guide)

Once the `android/` folder exists, make these two edits before your first
build — the app needs them to actually work, not just compile:

**1. Internet permission** — `android/app/src/main/AndroidManifest.xml`,
add inside the `<manifest>` tag, above `<application>`:
```xml
<uses-permission android:name="android.permission.INTERNET" />
```
Without this, every API call from the emulator/device silently fails.

**2. App label** — same file, on the `<application>` tag, set:
```xml
android:label="Smart Global Education Consult"
```

**3. Minimum SDK** — open `android/app/build.gradle` (or `build.gradle.kts`)
and make sure `minSdkVersion` (or `minSdk`) is at least 21. `flutter create`
usually sets a sane default already — just confirm it wasn't lowered by a
template.

**4. Application ID** — same file, `applicationId "com.yourcompany.sgec"`.
This is your unique Play Store package name — decide on it before your
first release build, since changing it later effectively creates a new
app listing.

## Where things stand

- `main.dart` wires up Riverpod + GoRouter + the app theme.
- `routes/app_router.dart` has the full route table incl. role-based
  redirects (student vs consultant vs admin land on different home shells
  after login).
- `features/` has one working screen per major user story (register, OTP,
  browse universities, upload documents, sign consent, track applications,
  chat, AI assistant, consultant dashboard, admin dashboard). Several admin
  tiles and the university/programme detail "Apply" button are marked
  `// TODO` — the backend endpoints they need already exist, so it's UI
  work, not backend work, to finish them.
- `core/api_client.dart` is the only place that talks HTTP — point
  `AppConstants.apiBaseUrl` (in `core/constants.dart`) at your backend, or
  override it at build time: `flutter build apk --dart-define=API_BASE_URL=https://api.yourdomain.com/api`.
